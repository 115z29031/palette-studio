
# AGENTS.md — Palette Studio

## 1. Project Overview

Palette Studio is a website designed to help artists, illustrators, and designers discover beautiful color combinations.

The main purpose is to provide color inspiration for people who are unsure which colors to use in their artwork or creative projects.

Users should be able to explore different palettes, generate random combinations, choose palettes based on moods, and save their favorite colors.

## 2. Target Audience

The target audience includes:
- Artists and illustrators
- Graphic designers
- Digital artists
- Students studying art and design
- Anyone interested in color combinations

The website should be beginner-friendly and easy to use.

## 3. Website Design

The visual style should feel like a modern, creative design studio.

### Color and appearance
- Background: warm cream (#FAF8F3)
- Main text: dark charcoal (#333333)
- Secondary text: muted gray (#777777)
- Cards: white (#FFFFFF)
- Accent: soft lavender (#B9A2CC)

### Design rules
- Use clean and minimal layouts.
- Display colors in large, clear swatches.
- Use rounded corners and subtle shadows.
- Keep enough spacing between sections.
- Use elegant headings and readable body text.
- Avoid clutter and unnecessary decorations.
- Make the website responsive on mobile and desktop.

## 4. Main Website Features

The website should include:

### Home
- Website title and introduction.
- A short explanation of the website.
- A featured color palette.

### Random Palette Generator
- Generate five-color palettes.
- Include a button to generate a new palette.
- Display the HEX code for each color.
- Allow users to copy individual HEX codes.

### Mood Categories
Include these moods:
- Dreamy
- Cozy
- Romantic
- Peaceful
- Mysterious
- Energetic

Each mood should have suitable color combinations.

### Color Styles
Include:
- Pastel
- Earthy
- Vibrant
- Muted
- Monochromatic

### Favorite Palettes
- Allow users to save their favorite palettes.
- Allow users to remove saved palettes.
- Keep saved palettes when the page is refreshed using browser local storage.

## 5. File Structure

Keep the project organized:

- index.html: Main website structure.
- styles.css: Website styling.
- script.js: Palette data, generation, and interactions.
- README.md: Project documentation.
- AGENTS.md: AI development instructions.

Do not put all code into one file.

## 6. Coding Rules

- Use HTML, CSS, and vanilla JavaScript.
- Do not introduce unnecessary frameworks or dependencies.
- Write clear and beginner-friendly code.
- Use descriptive variable and function names.
- Keep HTML, CSS, and JavaScript separate.
- Make sure all buttons and interactions work.
- Avoid duplicating code when existing functions can be reused.
- Do not remove existing features without permission.

## 7. Adding New Palettes

When adding a new palette:
- Include exactly five colors.
- Use valid HEX color codes.
- Give the palette a descriptive name.
- Assign it to an appropriate mood or style.
- Make sure the colors work well together.
- Display the HEX codes clearly.

## 8. Adding New Features or Pages

Before making changes, read this file.

When adding new pages or features:
- Follow the existing design system.
- Reuse existing components and styles.
- Keep navigation consistent.
- Make sure new features work on desktop and mobile.
- Maintain the website's creative and beginner-friendly purpose.

## 9. Future Development

The website should be easy to expand.

Possible future features include:
- Color harmony generator.
- Custom color selection.
- Uploading an image to extract colors.
- More mood categories.
- Downloading palettes as images.

All new features must follow the rules in this document.
